# manthey-precommit-hooks

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Pre-commit hooks for cleaning up AI/LLM-generated code.

## Overview

This repository provides custom [pre-commit](https://pre-commit.com/) hooks that help clean up common artifacts left behind when using LLMs or AI pair programmers:

### Hooks Included

- **`trim-underscores`** - Aggressively removes single leading underscores from Python identifiers generated by LLMs. Also removes excessive blank lines to keep code DRY and concise.

### Why These Hooks?

LLM-generated Python code often has two patterns that clutter source files:

1. **Unnecessary underscore prefixes**: LLMs often prefix variables/functions/classes with `_` to pretend they're meant to be "private" members of a library—when you just want a simple script.
2. **Excessive blank lines**: LLMs tend to over-use blank lines between code blocks to improve readability, but these often make diffs harder to review and clutter the file.

These hooks apply automated cleanup as a pre-commit step so your actual source control history stays clean without manual intervention.

## Installation & Usage

### As a Local Pre-commit Hook in Your Repository

Add this repository as a local hook reference in your project's `.pre-commit-config.yaml`:

```yaml
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/manthey/manthey-precommit-hooks
    rev: v1.0.0
    hooks:
      - id: trim-underscores
```

Then run pre-commit to install and test:

```bash
pre-commit install
pre-commit run --all-files  
```

### Standalone Usage

You can also run the hook script directly for one-time cleanup:

```bash
python hooks/trim_underscores.py --remove-underscores --remove-blank-lines path/to/file1.py path/to/file2.py
```
